# Nova Lift Platform (demo)

Responsive dashboard prototype with mock-only balances, tasks, and payment records. It is intentionally configured with no live payment processor, wallet address, or deposit/withdrawal logic.

## Run the mobile app

```powershell
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000`.

The `backend` and `admin-dashboard` folders are safe starter scaffolds for a future, compliance-reviewed implementation.
